Sistem Manajemen Toko Surya Jaya

Aplikasi Kasir & Inventaris Berbasis Desktop dengan Python Tkinter

Tentang Aplikasi

Sistem Manajemen Toko Surya Jaya adalah solusi aplikasi desktop yang dirancang untuk memudahkan pemilik toko dalam mengelola stok barang masuk, pembaruan harga, serta pencatatan transaksi penjualan kasir secara real-time.

Python 3 Tkinter GUI ttk.Treeview Desktop App

Fitur Utama

📦 Manajemen Stok Barang

Tambah barang baru, ubah harga dan stok, serta hapus data barang langsung dari tabel interaktif.

🛒 Sistem Kasir (POS)

Pilih barang via dropdown, kalkulasi subtotal otomatis, dan hitung total belanjaan secara akurat.

⚡ Update Stok Otomatis

Stok gudang berkurang secara otomatis begitu transaksi pembayaran selesai diproses.

🛡️ Validasi Data Input

Mencegah duplikasi nama barang, kesalahan input angka negatif, dan transaksi melebihi batas stok.
